## 📚 Правила GitHub

Все участники Motion Community обязаны соблюдать единый процесс разработки.

1. Использовать личный GitHub-аккаунт.
2. Работать только с репозиториями, к которым предоставлен доступ.
3. Создавать отдельную ветку для каждой задачи.
4. Не изменять `main` напрямую.
5. Создавать Pull Request перед объединением изменений.
6. Указывать понятные названия коммитов.
7. Проходить проверку кода ответственным Team Lead.
8. Не публиковать пароли, API-ключи и закрытые данные.
9. Не удалять репозитории и чужие ветки без согласования.
10. Соблюдать внутренние правила команды.

Полные правила: [CONTRIBUTING.md](https://github.com/motion-community/.github/blob/main/CONTRIBUTING.md).
